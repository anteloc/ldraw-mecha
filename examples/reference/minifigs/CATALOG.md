# Minifig movement catalog

Ten minifigs built from `data/categories/parts/minifig`, three movement clips each. Generated by `scripts/build_minifigs.py catalog` from `scripts/minifig_clips.py`; see `REPORT.md` for how they were built and checked.

## Channels (identical on every figure)

| Channel | Kind | Unit | Range | Meaning |
| --- | --- | --- | --- | --- |
| `neck` | joint (plan control) | rad | -3.142 … 3.142 | Head yaw about the neck stud; + turns the face to the figure's left |
| `shoulder_l` | joint (plan control) | rad | -12.57 … 12.57 | Left arm about its shoulder pin; + swings the arm forward and up (free spin) |
| `shoulder_r` | joint (plan control) | rad | -12.57 … 12.57 | Right arm about its shoulder pin; + swings the arm forward and up (free spin) |
| `wrist_l` | joint (plan control) | rad | -3.142 … 3.142 | Left hand about the arm socket axis; + rolls the held item's tip outward (+X) |
| `wrist_r` | joint (plan control) | rad | -3.142 … 3.142 | Right hand about the arm socket axis; + rolls the held item's tip outward (-X) |
| `hip_l` | joint (plan control) | rad | -1.571 … 1.571 | Left leg about the hip pin; + swings the leg forward (+pi/2 = seated) |
| `hip_r` | joint (plan control) | rad | -1.571 … 1.571 | Right leg about the hip pin; + swings the leg forward (+pi/2 = seated) |
| `move_forward` | whole figure (staging) | LDU | -400 … 400 | Offset of the hip-axis centre along the home facing direction |
| `move_left` | whole figure (staging) | LDU | -400 … 400 | Offset of the hip-axis centre toward the figure's home left |
| `move_up` | whole figure (staging) | LDU | -200 … 400 | Height offset of the hip-axis centre |
| `turn` | whole figure (staging) | rad | -12.57 … 12.57 | Yaw about the vertical through the hip-axis centre; + turns left (counter-clockwise seen from above) |
| `pitch` | whole figure (staging) | rad | -12.57 … 12.57 | Rotation about the hip axis (figure's left-right line); + leans forward |
| `roll` | whole figure (staging) | rad | -12.57 … 12.57 | Rotation about the figure's front-back line through the hip-axis centre; + leans toward the figure's left |

Figure frame: LDraw LDU, torso origin at the neck, −Y up, face along −Z, the figure's left is +X, feet at y = +72. Whole-figure channels rotate and move the figure about its hip-axis centre (0, 44, 0), 28 LDU above the ground. Order: translate, then turn, then pitch, then roll.

## Reusing a clip

- **Data only:** `clips/<id>.json` has the sparse keys (frame, value, Blender interpolation and easing) and the value baked at every frame for each of the 13 channels.
- **Blender:** every clip is an Action with one slot (`minifig_controller`) keyed on the controller's custom properties, so it plays on any minifig controller that has the same property names:

```python
import bpy
with bpy.data.libraries.load('/abs/path/output/minifigs/minifigs.blend', link=False) as (src, dst):
    dst.actions = ['MF03_knight.sword_slash']
action = dst.actions[0]
ctrl = bpy.data.objects['CTRL_minifig_05_chef']  # or any controller with the 13 properties
ad = ctrl.animation_data_create()
track = ad.nla_tracks.new()
strip = track.strips.new(action.name, 1, action)
strip.action_slot = action.slots[0]
```

Joint channels drive the plan's revolute bodies. The six whole-figure channels need the `MOVE_` empty and its drivers (see `scripts/blender/animate_minifigs.py`, `figure_mover`, and `minifig_clips.MOVE_DRIVERS`) or an equivalent transform on another rig.
- **Another model's minifig:** rig its seven joints with the same meanings (axes and origins from the same connector pairs, signs fixed by the tests in `author_plan`/`semantic_check`), name the controls as above, and the clip values apply unchanged. Clip keys are in radians/LDU in the figure's own frame.
